# AutoClip-Go 🎬 

一个基于 Go 1.24 开发的短视频全自动生产流水线。

## 💡 项目背景
本项目旨在通过 AI 和 Go 的并发特性，实现从“主题想法”到“成品视频”的自动化转化，极大地提高了自媒体创作效率。

## ✨ 技术亮点
* **并发素材抓取**：利用 Go 协程并发下载视频素材，并使用信号量（Semaphore）控制并发压力。
* **音画精准对齐**：通过 FFmpeg 的 `-shortest` 逻辑，实现视频随音频结束而精准截断。
* **自动化清理**：设计了临时文件粉碎机制，确保运行后本地磁盘整洁。
* **AI 驱动**：接入 DeepSeek-V3 模型进行文案策划和关键词提取。

## 🛠️ 快速开始
1. 配置 PEXELS_API_KEY 和 DEEPSEEK_API_KEY。
2. 运行 `go run . -t "沉没成本"`。
3. 产出位于 `output/final_movie.mp4`。
